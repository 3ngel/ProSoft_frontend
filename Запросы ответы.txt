Запрос авторизации:
user_verify
{
 login:'логин пользователя'
 password:'хеш от пароля по алгоритму md5'
}

Успех:
{
 user: 'ФИО пользователя'
 user_id: 'Идентификатор пользователя'
}
Неуспех:
{
 error: 'Ошибка аутентификации'
}

User_id нужен для куков

Запрос всех активов
get_all_activites
Запрос: (пустой), в куках передаются имя пользователя
Ответ:
массив с json-объектами
{ activites:
 [
  { 
  name: 'название актива',
  status:'статус актива',
  date_create:'дата добавление актива в систему',
  owner:'ФИО пользователя, к которому прикреплён актив',
  inventory_number:'инвертарный номер',
  type_object:'Тип актива',
  serial_number:'номер серии актива'
  }
 ]
}
